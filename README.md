## Ver.0.8.2 WindowsでVOICEVOXを使う方法（CORS回避）

GitHub PagesのHTTPSページからPC内のVOICEVOX (HTTP) への通信がブラウザに遮断される場合があります。Windowsローカル版はNode.js 20以降を使って同一オリジンで中継するため、この問題を回避します。

1. Windows PCでVOICEVOXを起動したままにする。 http://127.0.0.1:50021/docs が開くことを確認。
2. GitHubのCode → Download ZIPでリポジトリ全体をダウンロードし、ZIPを展開する。
3. Node.js 20以降（LTS推奨）をインストールする。
4. 展開フォルダー内の Windows-KY-Start.bat をダブルクリックする。
5. http://127.0.0.1:3000 を開く。音声接続先は /voicevox が自動選択される。
6. 「VOICEVOXに接続・話者一覧を取得」を押す。

**セキュリティ:** このローカルHTTPサーバーは127.0.0.1のみで待ち受けます。スマホや社外ネットワークから接続できる構成ではありません。VOICEVOX APIには許可した3経路だけを転送します。GitHub Pagesを開いた場合はブラウザのローカル通信制約が残ります。

# Ver.0.8.0: 外部音声エンジン接続試作

標準 `speechSynthesis` の声は不採用。VOICEVOX ENGINE の `/speakers` `/audio_query` `/synthesis` を使って、話者ごとに本物の別音声WAVを生成・再生します。外部エンジンが使えない場合は合成音声へ自動で戻りません（文字で活動を続行）。エンジン音声データや他者の録音・キャラクター素材は同梱していません。

**試す方法（PC）**：VOICEVOX公式エンジンまたはVOICEVOXエディタのエンジンを起動し、`http://127.0.0.1:50021` でAPIが応答する状態にしてください。アプリの接続先に入力し「外部音声に接続して声を取得」をクリック、話者を選びます。GitHub Pagesからアクセスする場合はVOICEVOXのCORS設定（`http://127.0.0.1:50021/setting`）にGitHub PagesのOriginを許可してエンジンを再起動する必要があります。ブラウザ側のPrivate Network Access/HTTPS混在の制限で接続不可の場合があります。PCローカルの `npm start` も試してください。

**スマホ公開版の制約**：GitHub PagesだけではVOICEVOX音声合成サーバーを提供できません。スマホからの利用には HTTPS の音声サーバー・APIプロキシの設置が別途必要です。現段階ではスマホ単独で自然な音声が聞ける完成版ではありません。

VOICEVOX音声利用時は使用する話者ごとの規約・商用条件・必要なクレジット表記を確認してください。作業員に録音・音声処理を行う場合は事前説明が必要です。外部に無断で有料音声や他人の録音素材をコピーしません。

# AI KY活動ナビゲーター Ver.0.6

外部APIキー・追加パッケージ不要のローカルWebアプリです。Node.js 20以降を使用します。

## デザイン

黄色・オレンジ・濃紺を中心に、青空と工事現場のイラスト、ヘルメット、斜線模様を組み合わせた明るいデザインです。文字はBIZ UDPゴシック／BIZ UDゴシックを優先し、未搭載の場合はメイリオ等の端末内フォントを使用します。外部フォント通信はありません。背景の原画は `site-scene.svg`、ヘルメット原画は `helmet.svg`。配信中のサーバーを再起動せず表示できるよう、背景はCSS内、ヘルメットはHTML内に埋め込んでいます。イラスト変更時は埋め込み側も更新してください。

デザイン変更後、ブラウザでデスクトップ表示と390px幅を確認しました。入力内容の復元と、スマホ幅で横にはみ出さないことを確認しています。

## 起動

Windows PCだけで試す場合は、フォルダー内の `index.html` をダブルクリックして開くこともできます。「起動完了：入力して開始できます。」と表示されたことを確認してください。直接ファイルを開いた場合の保存可否はブラウザに依存し、保存できない場合は画面に表示します。

このフォルダーで PowerShell を開き、`node server.mjs` を実行してください。Windows PCでは http://localhost:3000 を開きます。終了は Ctrl+C。ポート変更例：`$env:PORT=3001` の後に `node server.mjs`。npmが利用できる場合は `npm start` でも起動できます。

AndroidではPCと同じWi-Fiに接続し、`ipconfig` で確認したPCのIPv4アドレスを使って `http://192.168.x.x:3000` を開きます。接続できない場合はWindowsファイアウォールでプライベートネットワークからのNode.js接続を許可してください。PCが起動中の間だけ利用できます。インターネットへの公開は不要です。

## 実装済み

- 人数1～20名と作業内容の確認、作業員順の危険→対策のテキスト入力。
- 対策後の定型の受け止め、手動の次へ、全員の一覧表示。
- 重点安全目標の入力と、内容を表示してからの確認完了。
- 男性／女性ナレーター設定、2種類の話し方、読み上げ開始・停止・再読み上げ。
- Web Speech APIの日本語音声検出。日本語音声なし・性別を判別できる音声なしを明示。
- スマートフォンとPC向けのレスポンシブ画面。作業内容・人数・回答途中の文章・進行状況を同じブラウザに自動保存し、再読み込み後に復元します。

読み上げはボタン操作で開始します。質問が変わった際は停止します。性別はAPIから取得できないため既知の音声名で判別し、任意の日本語音声を手動選択することもできます。話し方は速度・高さの調整であり声優音声を生成する機能ではありません。外部送信を避けるため `localService=true` の端末音声だけを使用し、リモート音声は使用しません。端末・OS・ブラウザによって音声の種類と動作は異なります。

## 未実装・今後の構成

音声認識、AIによる一言コメント、全体録音、KYシートPDF生成・セット保存、ローカルAI接続は未実装です。「AI」はアプリ名でありVer.0.6は生成AIを呼び出しません。危険・対策は入力文をそのまま表示し、定型コメントで内容を追加しません。

進行ロジックと下書き保存は `flow.js`、画面と音声アダプターは `ui.js`、配信は `server.mjs` に分離しています。`node build.mjs` でブラウザ用の `app.js` を生成します。`app.js` は直接編集せず、ソース変更後に再生成してください。通常スクリプト形式のためHTMLを直接開く場合もモジュール読み込み制限を受けません。将来はコメント生成用のプロバイダーを別モジュールに追加してローカルAI等へ切り替える想定です。生成内容を追加しない規則とコメントの採用手順は拡張時にも別途維持する必要があります。

入力はブラウザのlocalStorageに保存します。同じブラウザ・同じアドレスで開くと復元されます。別端末・別ブラウザ・別アドレスとは共有されません。ブラウザのデータ削除やプライベートモード終了などでは消える場合があります。保存できないときは画面に警告します。「保存内容をすべて消去」で人数・作業内容・回答を初期化できます。「最初からやり直す」では人数と作業内容を残し回答・進行状況を初期化します。外部フォントやCDN、解析サービスは使用しません。
